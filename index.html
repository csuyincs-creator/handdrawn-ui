是怎么做到的

核心就三步，看这段（真实运行的就是它）：

// 1. 采样：把一条直线拆成每 8px 一个点
function sampleLine(x1, y1, x2, y2, step = 8) {
  const n = Math.max(2, Math.ceil(Math.hypot(x2 - x1, y2 - y1) / step));
  return Array.from({ length: n + 1 }, (_, i) =>
    [x1 + (x2 - x1) * i / n, y1 + (y2 - y1) * i / n]);
}

// 2. 抖动：每个点随机挪一点
const jitter = (pts, rnd, amp) =>
  pts.map(([x, y]) => [x + (rnd() * 2 - 1) * amp, y + (rnd() * 2 - 1) * amp]);

// 3. 画两遍——这是"手绘感"的真正来源
//    人手画线会来回蹭，两笔轻微错开就像了
function stroke(pts, rnd, amp) {
  return path(jitter(pts, rnd, amp)) + path(jitter(pts, rnd, amp * 1.4));
}

随机数用固定种子的 mulberry32，所以同一个种子画出来的线条每次都一样 （不固定的话每次刷新都在抖，看起来像坏了）。想"沸腾"就生成三份不同抖动的版本，用 CSS 轮流显示。

自己动手改

想调手感就改这几个数：rough（抖动幅度，默认 1.5）、 step（采样密度，默认 8，越小越细腻）、boil（沸腾幅度，0 就静止）。 想加新形状就写个返回点数组的函数，套上 stroke() 即可—— 圆形、方框、勾选、箭头全都是这么来的。
